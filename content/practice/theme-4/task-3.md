# Задача 4.3: Складені логічні умови (and, or, not)

### 🏆 Рівень складності: **Реконструктивний** (Логічний аналіз)

## 📘 Короткі теоретичні відомості

Коли програма має приймати рішення на основі кількох факторів одночасно, прості оператори порівняння комбінують за допомогою **логічних операторів** (and, or, not):

* **`and`** (Логічне І / Кон'юнкція) — повертає `True` лише тоді, коли **обидві** умови є істинними. Якщо хоча б одна умова хибна, весь вираз стає `False`.
* **`or`** (Логічне АБО / Диз'юнкція) — повертає `True`, якщо хоча б **одна** з умов є істинною. Вираз стає `False` лише тоді, коли обидві умови хибні.
* **`not`** (Логічне НЕ / Заперечення) — змінює логічне значення на протилежне (перетворює `True` на `False` і навпаки).

**Приклад:**

```python
has_ticket = True
has_passport = False

# Для посадки на рейс потрібні ОБИДВА документи
if has_ticket and has_passport:
    print("Посадка дозволена")
else:
    print("Відмовлено в посадці") # Програма вибере цю гілку

```

Напишіть програму валідації, яка виконує такі інженерні кроки:

1. Створіть змінну `is_admin_input` та присвойте їй текст, зчитаний через запит `"Ви маєте права адміністратора? (yes/no): "`.
2. Створіть змінну `pin_code` та присвойте їй ціле число, зчитане через запит `"Введіть 4-значний ПІН-код доступу: "` (використайте `int(input(...))`).
3. Створіть логічну змінну `is_admin`, яка набуде значення `True`, якщо користувач ввів `"yes"`, і `False` у будь-якому іншому випадку (це можна записати як `is_admin_input == "yes"`).
4. За допомогою оператора `if` та логічного зв'язку **`and`** перевірте дві умови одночасно: чи є користувач адміном (`is_admin`) **ТА** чи дорівнює введений `pin_code` числу `2026`.

6. Якщо хоча б одна з умов порушена, через блок `else` виведіть:
