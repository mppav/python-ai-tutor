# Задача 4.1: Логічний тип bool та прості умови if-else

### 🏆 Рівень складності: **Репродуктивний** (Базові операції)

## 📘 Короткі теоретичні відомості

Для керування логікою виконання програми у Python використовуються умовні оператори. В основі будь-якої умови лежить логічний тип даних **`bool`**, який може набувати лише одного з двох значень:

* **`True`** (Істина)
* **`False`** (Хибність)

Логічні значення зазвичай з'являються в результаті роботи операторів порівняння: `>` (більше), `<` (менше), `>=` (більше або дорівнює), `<=` (менше або дорівнює), `==` (дорівнює), `!=` (не дорівнює).

Конструкція **`if - else`** дозволяє спрямувати виконання програми за однією з двох гілок:

```python
if умова:
    # код, який виконається, якщо умова має значення True
else:
    # код, який виконається, якщо умова має значення False

```

> ⚠️ **Важливо про синтаксис:** Після ключових слів `if` та `else` обов'язково ставиться **двокрапка (`:`)**, а всі команди всередині блоків повинні мати однакові **відступи (4 пробіли)** від лівого краю.


## 🎯 Технічне завдання

Уявіть, що ви створюєте модуль автоматичної перевірки балів для нашої освітньої LMS-платформи. Якщо студент набрав достатню кількість балів, система повинна надати доступ до наступного рівня, інакше — запропонувати повторити матеріал.

Напишіть програму, яка реалізує цю логіку:

1. Створіть змінну `student_score` та присвойте їй ціле число, зчитане від користувача через запит `"Введіть кількість набраних балів: "` (не забудьте сконвертувати результат `input()` в `int`).
2. За допомогою умовного оператора `if` перевірте, чи значення `student_score` є **більшим або дорівнює `50**`.
3. Якщо умова виконується (`True`), виведіть у консоль повідомлення:
`Доступ дозволено. Перехід до наступного модуля!`
4. Якщо умова не виконується (`False`), через блок `else` виведіть повідомлення:
`Доступ заблоковано. Необхідно набрати мінімум 50 балів.`
