# Задача 4.2: Множинне розгалуження за допомогою elif

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Складні розгалуження)


## 📘 Короткі теоретичні відомості

Конструкція `if - else` чудово підходить для задач, де є лише два варіанти розвитку подій. Проте на практиці часто виникають ситуації, коли умов значно більше. Для перевірки кількох послідовних умов у Python використовують ключове слово **`elif`** (скорочення від *else if*).

Програма перевіряє умови зверху вниз. Як тільки якась умова виявляється істинною (`True`), виконується відповідний блок коду, а всі інші умови та блоки `elif` / `else` повністю ігноруються. Блок `else` ставиться в самому кінці й виконується лише тоді, коли жодна з попередніх умов не виявилася правильною.

**Синтаксична структура:**

```python
if умова_1:
    # виконується, якщо умова_1 істинна
elif умова_2:
    # виконується, якщо умова_1 хибна, але умова_2 істинна
else:
    # виконується, якщо всі попередні умови хибні

```

2. Реалізуйте множинне розгалуження для перевірки таких умов:
