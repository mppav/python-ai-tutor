# Задача 7.2: Динамічна модифікація списків (append, insert, pop)

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Модифікація структур)

## 📘 Короткі теоретичні відомості

На відміну від текстових рядків, списки в Python є **змінними (mutable)** об'єктами. Це означає, що ми можемо додавати, видаляти або замінювати елементи безпосередньо в існуючому списку в пам'яті.

Для динамічної модифікації списків використовуються такі вбудовані методи:

* **`.append(element)`** — додає вказаний елемент у **кінець** списку.
* **`.insert(index, element)`** — вставляє елемент на **конкретну позицію (`index`)**, зсуваючи всі наступні елементи праворуч.
* **`.pop(index)`** — видаляє елемент із вказаного індексу та повертає його. Якщо індекс не вказати (`.pop()`), буде видалено **останній** елемент.

**Приклад:**

```python
tech_stack = ["Python", "Django"]

tech_stack.append("PostgreSQL") # ["Python", "Django", "PostgreSQL"]
tech_stack.insert(1, "Git")     # ["Python", "Git", "Django", "PostgreSQL"]
removed_item = tech_stack.pop() # Видаляє "PostgreSQL"

```
