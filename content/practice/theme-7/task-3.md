# Задача 7.3: Перебір елементів списку за допомогою циклу for

### 🏆 Рівень складності: **Реконструктивний** (Обробка масивів даних)

## 📘 Короткі теоретичні відомості

У реальних проєктах списки рідко залишаються статичними — найчастіше нам потрібно послідовно обробити кожен їхній елемент: перевірити умови, виконати математичні розрахунки або вивести дані користувачу.

Найбільш елегантний та ефективний спосіб зробити це в Python — використати цикл **`for`**. При ітерації по списку змінна циклу на кожному кроці автоматично набуває значення чергового елемента (від першого до останнього).

**Приклад:**

```python
frameworks = ["Django", "FastAPI", "Flask"]

for framework in frameworks:
    print(f"Робочий інструмент: {framework}")

```

*У цьому прикладі цикл виконається рівно 3 рази. Спочатку змінна `framework` дорівнюватиме `"Django"`, потім `"FastAPI"`, а на фінальному кроці — `"Flask"`.*

## 🎯 Технічне завдання

Уявіть, що ви розробляєте модуль автоматичного сповіщення для нашої LMS-платформи. Система повинна пройтися по списку користувачів, які зараз перебувають у мережі, та надіслати кожному персональне привітання в консоль.

Напишіть інженерний скрипт, який реалізує цей алгоритм:

1. Створіть змінну-список `online_users` і внесіть туди чотири текстові імені: `"Анна"`, `"Максим"`, `"Дмитро"`, `"Олена"`.
2. За допомогою циклу `for` організуйте перебір елементів списку `online_users`. Назвіть змінну циклу `user`.
3. Усередині тіла циклу (з відступом у 4 пробіли) виведіть для кожного користувача повідомлення точного формату:
   
`Користувач [значення_змінної_user] зараз в мережі. Надсилаємо сповіщення...`
