# Задача 1.1: Перше виведення даних та коментарі

### 🏆 Рівень складності: **Репродуктивний** (Базові операції)

## 📘 Короткі теоретичні відомості

У мові програмування Python для виведення текстової та числової інформації в консоль використовується вбудована функція `print()`. Текст, який необхідно вивести, обов'язково береться в одинарні (`'...'`) або подвійні (`"..."`) лапки.

**Приклад:**
`print("Привіт, світе!")`

**Коментарі** в Python — це нотатки для розробника, які повністю ігноруються інтерпретатором під час виконання коду. Вони слугують для документування програм. Однорядкові коментарі починаються із символу решітки (`#`).

## 🎯 Технічне завдання

Вам необхідно написати просту лінійну програму, яка послідовно виконує такі інженерні кроки:

1. На першому рядку створіть **однорядковий коментар** із текстом: `Лабораторна робота: Модуль 1`.
2. На другому рядку за допомогою функції `print()` виведіть у консоль класичну фразу початківця: `Hello, Python!`.
3. На третьому рядку за допомогою функції `print()` виведіть число поточного року: `2026`.
