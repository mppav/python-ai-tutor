# Задача 1.3: Виправлення синтаксичних помилок у шаблоні

### 🏆 Рівень складності: **Реконструктивний** (Дебагінг коду)

## 📘 Короткі теоретичні відомості

Під час написання коду на Python інтерпретатор суворо стежить за дотриманням правил синтаксису мови. Якщо припуститися помилки, програма не запуститься, а в консолі з'явиться повідомлення про помилку:

* **`SyntaxError`** (Синтаксична помилка) — виникає, наприклад, якщо забути закрити лапку для рядка.
* **`NameError`** (Помилка імені) — виникає, якщо викликати функцію або змінну, якої не існує (наприклад, написати `Print` з великої літери замість вбудованої `print`, або забути взяти звичайний текст у лапки, через що Python подумає, що це назва змінної).


## 🎯 Технічне завдання

Ваш колега-початківець написав код для виведення статусів системи, але програма падає з помилками.

Скопіюйте цей код у вікно середовища розробки, запустіть його, щоб проаналізувати помилки, а потім виправте всі недоліки так, щоб програма успішно вивела два рядки тексту.

**Код із помилками для копіювання:**

```python
Print("Ініціалізація системи)
print(Успішно!)

```
