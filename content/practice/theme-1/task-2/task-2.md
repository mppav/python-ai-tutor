# Задача 1.2: Форматування виводу декількох аргументів

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Робота з аргументами)


## 📘 Короткі теоретичні відомості

Функція `print()` може виводити не лише одне значення, а й одразу декілька. Для цього аргументи всередині дужок потрібно розділити комою. Під час виконання програми Python автоматично підставить символи пробілу між цими значеннями при виведенні їх у консоль.

**Приклад:**
`print("Моя улюблена цифра:", 7)`
Вивід у консолі: `Моя улюблена цифра: 7`


## 🎯 Технічне завдання

Сформуйте вивід інформації про себе, використовуючи лише **одну** функцію `print()`, передаючи їй декілька аргументів через кому.
