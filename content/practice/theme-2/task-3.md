# Задача 2.3: Явне приведення типів (str до int/float)

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Перетворення типів)

## 📘 Короткі теоретичні відомості

Як ви вже знаєте з попереднього завдання, функція `input()` завжди повертає дані у вигляді тексту (тип `str`). Якщо користувач введе число `10`, Python сприйме це як рядок з двох символів `'1'` та `'0'`.

Спробувавши виконати арифметичну операцію з таким значенням (наприклад, додавання), програма видасть помилку `TypeError`, тому що не можна математично додавати текст до числа.

Для перетворення тексту на число використовують **явне приведення типів**:

* **`int()`** — перетворює рядок на ціле число (якщо в рядку немає крапки).
* **`float()`** — перетворює рядок на дійсне (дробове) число.

**Приклад:**

```python
age_str = input("Введіть ваш вік: ") # Отримуємо рядок, наприклад "20"
age = int(age_str)                  # Конвертуємо у ціле число 20
next_year_age = age + 1             # Тепер математичні операції дозволені!

```
