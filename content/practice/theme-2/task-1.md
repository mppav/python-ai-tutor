# Задача 2.1: Оголошення змінних та арифметичні операції

### 🏆 Рівень складності: **Репродуктивний** (Базові операції)

## 📘 Короткі теоретичні відомості

У мові Python **змінна** — це іменована область пам'яті, яка зберігає певне значення. Оголошення змінної відбувається в момент присвоєння їй значення за допомогою оператора рівності `=`.

**Приклад:**

```python
player_name = "Артур"  # Текстовий тип (str)
gold_count = 150       # Ціле число (int)

```

Python підтримує стандартні арифметичні операції:

* Додавання `+`
* Віднімання `-`
* Множення `*`
* Ділення `/` (результат ділення завжди є дійсним числом типу `float`)

Ви можете виконувати математичні операції безпосередньо всередині функції `print()` або спочатку зберегти результат у нову змінну, а потім вивести її.

## 🎯 Технічне завдання

Уявіть, що ви розробляєте систему обліку ігрових ресурсів. Напишіть програму, яка виконує такі кроки:

1. Створіть змінну `initial_gold` (початкове золото) та присвойте їй ціле число `500`.
2. Створіть змінну `reward` (нагорода) та присвойте їй ціле число `250`.
3. Створіть змінну `total_gold`, яка автоматично обчислює суму початкового золота та нагороди за допомогою оператора додавання `+`.
4. За допомогою **однієї** функції `print()` виведіть у консоль повідомлення точного формату:
`Загальна кількість золота: [значення_змінної_total_gold]`
