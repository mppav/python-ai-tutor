# Задача 2.4: Обчислення площі та периметра фігури

### 🏆 Рівень складності: **Творчий** (Математичне моделювання)

## 📘 Короткі теоретичні відомості

В інженерних задачах часто доводиться автоматизувати геометричні розрахунки. Для обчислення характеристик прямокутника зі сторонами $a$ та $b$ використовуються базові математичні формули:

* **Периметр (P):** сума довжин усіх сторін фігури:

P = 2(a + b)

* **Площа (S):** добуток довжини на ширину:

S = a * b

Нагадуємо, що в Python операція множення позначається зірочкою `*`, а для пріоритету виконання операцій (як у математиці) використовуються круглі дужки `()`.

## 🎯 Технічне завдання

Уявіть, що ви розробляєте модуль для автоматизованої системи проектування (CAD), який вираховує параметри земельної ділянки під серверну станцію. Напишіть програму, яка виконує такі інженерні кроки:

1. Запишіть у змінну `side_a` довжину ділянки, отримавши її від користувача через запит `"Введіть довжину ділянки (метрів): "` та одразу конвертувавши у дробове число (`float`).
2. Запишіть у змінну `side_b` ширину ділянки, отримавши її від користувача через запит `"Введіть ширину ділянки (метрів): "` та одразу конвертувавши у дробове число (`float`).
3. Створіть змінну `perimeter` для обчислення периметра ділянки за формулою.
4. Створіть змінну `area` для обчислення площі ділянки за формулою.
5. Виведіть результат розрахунків у консоль у вигляді двох окремих рядків точного формату:
`Периметр ділянки: [значення_perimeter] м.`
`Площа ділянки: [значення_area] кв. м.`
