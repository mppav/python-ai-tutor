# Задача 5.2: Накопичення значень (агрегація) у циклі

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Агрегація даних)

## 📘 Короткі теоретичні відомості

Окрім простого підрахунку кількості повторень, цикли часто використовують для **агрегації** — поступового накопичення суми, добутку або формування текстового рядка з кожною новою ітерацією.

Для цього використовують спеціальну змінну, яку називають **суматором** або **акумулятором**.

Головні правила роботи з акумулятором:

1. **Створення до початку циклу:** змінну для накопичення суми обов'язково оголошують *перед* оператором `while`. Якщо ми рахуємо суму чисел, її початкове значення зазвичай дорівнює `0`.
2. **Накопичення всередині циклу:** на кожному кроці до поточного значення акумулятора додається нове число.
3. **Виведення результату:** фінальний результат виводиться лише *після* завершення циклу (без відступів від лівого краю).

**Приклад:**

```python
total_sum = 0  # Акумулятор
number = 1     # Лічильник

while number <= 3:
    total_sum = total_sum + number  # Додаємо поточне число до суми
    number += 1                     # Переходимо до наступного числа

print("Сума чисел від 1 до 3 дорівнює:", total_sum) # Виведе: 6

```

## 🎯 Технічне завдання

Уявіть, що ви пишете модуль аналітики для фінансового робота, який підраховує загальну суму транзакцій або витрат за фіксований період (наприклад, за робочий тиждень — 5 днів).

Напишіть інженерний скрипт, який за допомогою циклу `while` послідовно запитує у користувача суму витрат за кожен із 5 днів та вираховує їхній загальний підсумок:

1. Створіть змінну-лічильник `day` та присвойте їй початкове значення `1`.
2. Створіть змінну-акумулятор `total_expenses` із початковим значенням `0`.
3. Напишіть цикл `while`, який виконується, поки значення `day` **менше або дорівнює `5**`.
4. Усередині циклу:

* Запитайте у користувача суму витрат за поточний день за допомогою тексту: `"Введіть витрати за день № [значення_лічильника]: "` (зчитане значення обов'язково конвертуйте у дробове число `float`).
* Додайте отримане число до змінної `total_expenses`.
* Збільште лічильник `day` на `1`.

1. Після повного завершення циклу виведіть у консоль фінальний результат точного формату:
`Загальні витрати за 5 днів: [значення_змінної_total_expenses] грн.`
