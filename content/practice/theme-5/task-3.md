# Задача 5.3: Управління циклами за допомогою break та continue

### 🏆 Рівень складності: **Реконструктивний** (Алгоритмічний аналіз)

## 📘 Короткі теоретичні відомості

Іноді виникає потреба змінити стандартну логіку роботи циклу прямо під час його виконання. Для цього в Python існують два спеціальні оператори управління — `break` та `continue`:

* **`break`** — миттєво перериває виконання всього циклу та передає керування командам, які йдуть *після* нього. Його часто використовують для екстреного виходу, наприклад, при виявленні критичної помилки або примусовій зупинці процесу.
* **`continue`** — достроково завершує роботу *поточної ітерації* (кроку) циклу. Програма ігнорує всі команди, що написані нижче цього оператора в тілі циклу, і відразу переходить до перевірки умови для наступного кроку.

**Приклад використання `break`:**

```python
while True:
    command = input("Введіть команду (або stop для виходу): ")
    if command == "stop":
        break  # Цикл зупиниться повністю
    print("Виконую:", command)

```

## 🎯 Технічне завдання

У системах автоматизації інфраструктури (DevOps) скрипти моніторингу можуть працювати в нескінченному режимі, постійно перевіряючи статус серверів. Проте при виявленні критичної загрози безпеці роботу потрібно негайно зупинити.

Напишіть симуляційну програму для перевірки мережевих вузлів, яка використовує механізм переривання циклу:

1. Створіть змінну-лічильник `node_id` із початковим значенням `1`.
2. Напишіть нескінченний цикл за допомогою конструкції **`while True:`**.
3. Усередині циклу:

* Запитайте статус поточного вузла у користувача за допомогою тексту: `"Введіть статус вузла № [значення_лічильника] (ok / error / critical): "`. Збережіть відповідь у змінну `status`.
* Якщо `status` дорівнює ряду `"critical"`, виведіть у консоль повідомлення: `Критична загроза виявлена! Аварійна зупинка моніторингу.` та повністю перервіть роботу циклу за допомогою оператора **`break`**.
* Якщо `status` дорівнює ряду `"error"`, виведіть у консоль: `Вузол несправний. Пропускаємо тестування компонентів.` та за допомогою оператора **`continue`** завершіть поточну ітерацію (не забудьте збільшити лічильник перед цим!).
* У звичайному випадку (якщо статус `"ok"`), виведіть у консоль: `Вузол працює стабільно. Повна діагностика завершена.`.
* Наприкінці тіла циклу (для переходів на наступний крок) збільшуйте значення `node_id` на `1`.
