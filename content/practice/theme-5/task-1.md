# Задача 5.1: Базовий цикл while та лічильники

### 🏆 Рівень складності: **Репродуктивний** (Базові операції)


## 📘 Короткі теоретичні відомості

У програмуванні для багаторазового повторення певної послідовності команд використовують **цикли**. Цикл **`while`** (поки) виконує блок коду доти, доки певна логічна умова залишається істинною (`True`).

Для керування кількістю повторень (ітерацій) циклу зазвичай використовують змінну-**лічильник**.

Робота з лічильником складається з трьох обов'язкових кроків:

1. **Ініціалізація:** створення змінної-лічильника з початковим значенням перед початком циклу.
2. **Перевірка умови:** вказівка граничного значення лічильника в умові `while`.
3. **Інкремент (оновлення):** збільшення значення лічильника всередині циклу. Якщо забути оновити лічильник, умова циклу ніколи не стане хибною, і програма зависне в **нескінченному циклі**.

**Приклад:**

```python
counter = 1  # 1. Ініціалізація
while counter <= 3:  # 2. Перевірка умови
    print("Ітерація №", counter)
    counter = counter + 1  # 3. Інкремент (або коротко: counter += 1)

```

Напишіть програму, яка реалізує цей алгоритм за допомогою циклу `while`:

1. Створіть змінну-лічильник `ping_count` та присвойте їй початкове ціле число `1`.
2. Напишіть цикл `while`, який продовжує виконуватися, поки значення `ping_count` **менше або дорівнює `5**`.
3. Усередині циклу виведіть у консоль повідомлення точного формату:
`Тестування датчика... Імпульс № [значення_змінної_ping_count]`
4. Наприкінці тіла циклу обов'язково збільшуйте значення `ping_count` на `1`.
