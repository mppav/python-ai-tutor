# Задача 3.1: Індексація рядків та визначення довжини len()

### 🏆 Рівень складності: **Репродуктивний** (Базові операції)

## 📘 Короткі теоретичні відомості

У мові Python текстовий рядок (`str`) є впорядкованою послідовністю символів. Кожен символ у рядку має свій порядковий номер, який називається **індексом**.

Важливі правила індексації в Python:

* Нумерація символів завжди починається з **0**. Тобто перший символ рядка має індекс `0`, другий — `1` і так далі.
* Python підтримує **негативну індексацію**. Індекс `-1` вказує на останній символ рядка, `-2` — на передостанній тощо.
* Для отримання конкретного символу використовують квадратні дужки `[]` після назви змінної.

**Приклад:**

```python
word = "Python"
print(word[0])   # Виведе: P
print(word[-1])  # Виведе: n (останній символ)

```

Для того щоб дізнатися загальну кількість символів у рядку (включаючи пробіли та розділові знаки), використовують вбудовану функцію **`len()`**.

**Приклад:**

```python
word = "Python"
print(len(word)) # Виведе: 6

```
