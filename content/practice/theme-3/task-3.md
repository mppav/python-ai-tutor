# Задача 3.3: Модифікація рядків базовими методами

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Методи об'єктів)

## 📘 Короткі теоретичні відомості

У Python рядки є об'єктами, що мають вбудовані функції для обробки та трансформації тексту, які називаються **методами**. Щоб викликати метод, потрібно після назви змінної або рядка поставити крапку `.` та вказати ім'я методу з дужками.

Ось базові методи для зміни регістру тексту:

* **`.upper()`** — переводить усі символи рядка у ВЕЛИКІ (верхній регістр).
* **`.lower()`** — переводить усі символи рядка у малі (нижній регістр).
* **`.capitalize()`** — робить першу літеру рядка великою, а всі інші — малими.

> ⚠️ **Критично важлива властивість рядків (Immutability):**
> Рядки в Python є **незмінними**. Це означає, що жоден метод не змінює оригінальний рядок у пам'яті, а лише створює і повертає новий змінений рядок. Якщо ви хочете зберегти результат роботи методу, його потрібно присвоїти новій змінній або перезаписати стару.

**Приклад:**

```python
text = "python"
text.upper()     # Оригінальний рядок НЕ змінився!
print(text)      # Виведе: python

upper_text = text.upper() # Зберігаємо результат у нову змінну
print(upper_text)         # Виведе: PYTHON

```
