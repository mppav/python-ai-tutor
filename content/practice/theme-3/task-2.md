# Задача 3.2: Використання зрізів рядків [start:stop:step]

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Робота з послідовностями)

## 📘 Короткі теоретичні відомості

Якщо індексація дозволяє отримати лише один символ, то **зрізи (slices)** дають змогу вирізати з рядка цілий підрядок. Синтаксис зрізу виглядає так: `рядок[start:stop:step]`.

Параметри зрізу:

* **`start`** — індекс, з якого починається зріз (включається).
* **`stop`** — індекс, на якому зріз закінчується (**НЕ включається**).
* **`step`** — крок, з яким вибираються символи (за замовчуванням дорівнює `1`).

Будь-який із цих параметрів можна пропустити:

* `рядок[:stop]` — зріз від самого початку до індексу `stop`.
* `рядок[start:]` — зріз від індексу `start` до самого кінця рядка.
* `рядок[:]` — повна копія рядка.
* `рядок[::-1]` — розвертає рядок у зворотному напрямку (крок `-1`).

**Приклад:**

```python
text = "Intelligence"
print(text[0:4])   # Виведе: Inte (символи з індексами 0, 1, 2, 3)
print(text[:5])    # Виведе: Intel (від початку до 4-го індексу включно)
print(text[5:])    # Виведе: ligence (від 5-го індексу до кінця)

```
