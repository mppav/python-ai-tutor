# Задача 3.4: Пошук та заміна підрядків у тексті

### 🏆 Рівень складності: **Творчий** (Алгоритми обробки текстів)

## 📘 Короткі теоретичні відомості

Для автоматизованого аналізу та редагування текстів у Python часто використовуються два потужні вбудовані методи рядків:

* **`.find(sub)`** — шукає підрядок `sub` в оригінальному рядку. Метод повертає **індекс першого символу** знайденого підрядка. Якщо такий підрядок у тексті взагалі не знайдено, метод повертає спеціальне число `-1`.
* **`.replace(old, new)`** — знаходить у тексті всі фрагменти `old` і замінює їх на новий фрагмент `new`. Як і всі методи рядків, він не змінює початковий об'єкт, а повертає новий текстовий рядок із виконаними замінами.

**Приклад:**

```python
text = "Курс по Java"
# Пошук
position = text.find("Java")
print(position)  # Виведе: 8 (індекс, з якого починається слово Java)

# Заміна
new_text = text.replace("Java", "Python")
print(new_text)  # Виведе: Курс по Python

```
