# Задача 10.2: Конструктор __init__ та атрибути об'єкта

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Ініціалізація стану)


## 📘 Короткі теоретичні відомості

Порожні класи, які ми розглянули в попередній задачі, не мають практичної користі. Об'єкти стають корисними, коли вони містять у собі конкретні дані. Змінні всередині об'єкта в термінах ООП називаються **атрибутами** (або властивостями).

Щоб задати об'єкту початкові атрибути прямо в момент його створення, використовують спеціальний вбудований метод (функцію класу) — **`__init__`** (від англ. *initialize* — ініціалізувати). Його називають **конструктором класу**.

**Приклад оголошення конструктора:**

```python
class Robot:
    # Конструктор класу
    def __init__(self, name, model):
        self.name = name    # Атрибут об'єкта 1
        self.model = model  # Атрибут об'єкта 2

```

* **`self`** — це обов'язковий перший параметр будь-якого методу в класі. Він є посиланням на той конкретний об'єкт, який зараз створюється або обробляється. Через `self.назва_атрибута` Python розуміє, що цю змінну потрібно "прив'язати" до самого об'єкта.
* Параметри `name` та `model` — це дані, які ми передаємо ззовні під час створення об'єкта.

**Створення об'єкта з аргументами:**

```python
# Передаємо реальні дані всередину конструктора (параметр self передається автоматично!)
my_robot = Robot("Арчі", "R2-D2")

# Доступ до атрибутів через крапку
print(my_robot.name)   # Виведе: Арчі
print(my_robot.model)  # Виведе: R2-D2

```


## 🎯 Технічне завдання

Уявіть, що ви продовжуєте розбудовувати ООП-архітектуру нашої освітньої платформи. Тепер вам потрібно навчити клас `CloudServer` приймати конкретні технічні характеристики сервера під час його створення.

Напишіть інженерний скрипт, який реалізує конструктор класу та зчитує атрибути:

1. Оголосіть клас з назвою `CloudServer`.
2. Усередині класу створіть конструктор **`def __init__(self, ip_address, ram_size):`**, який приймає два вхідні параметри: IP-адресу (`ip_address`) та об'єм оперативної пам'яті (`ram_size`).
3. У тілі конструктора (з відступами) ініціалізуйте два відповідні атрибути об'єкта за допомогою ключового слова `self` (тобто `self.ip_address = ip_address` та `self.ram_size = ram_size`).
4. Поза межами класу створіть один об'єкт цього класу у змінну `production_server`, передавши в дужках два аргументи: IP-адресу `"192.168.1.50"` та об'єм пам'яті `16` (ціле число).
5. За допомогою функції `print()` та звернення через крапку виведіть характеристики створеного сервера в консоль точного формату:
`Сервер [значення_атрибута_ip_address] має [значення_атрибута_ram_size] ГБ оперативної пам'яті.`
