# Задача 10.3: Методи класу та взаємодія зі станом об'єкта

### 🏆 Рівень складності: **Реконструктивний** (Поведінка об'єктів)


## 📘 Короткі теоретичні відомості

Об'єкти в ООП поєднують у собі не лише дані (атрибути), а й пов'язані з ними дії. Функції, які оголошуються всередині класу і визначають поведінку його об'єктів, називаються **методами**.

Головна особливість методів полягає в тому, що вони можуть зчитувати або змінювати внутрішній стан об'єкта (його атрибути). Для цього першим параметром у будь-якому методі обов'язково вказують **`self`**.

**Приклад оголошення та виклику методу:**

```python
class Robot:
    def __init__(self, name):
        self.name = name
        self.charge = 100  # Початковий заряд у відсотках

    # Метод, що описує дію робота
    def report_status(self):
        # Метод отримує доступ до атрибутів через self
        print(f"Робот {self.name} заряджений на {self.charge}%")

```

Щоб викликати метод, спочатку вказують ім'я конкретного об'єкта, ставлять крапку, а потім пишуть назву методу з круглими дужками: `назва_об'єкта.назва_метод()`.

```python
bot = Robot("Оптімус")
bot.report_status()  # Виведе: Робот Оптімус заряджений на 100%

```
