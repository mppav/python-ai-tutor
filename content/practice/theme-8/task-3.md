# Задача 8.3: Ітерація по словниках (методи .keys(), .values(), .items())

### 🏆 Рівень складності: **Реконструктивний** (Обхід структур даних)


## 📘 Короткі теоретичні відомості

Для перебору (ітерації) елементів словника за допомогою циклу `for` у Python існують три спеціальні методи. Вони дозволяють чітко вказати інтерпретатору, яку саме частину даних ми хочемо отримати на кожному кроці:

* **`.keys()`** — цикл перебирає лише **ключі** словника (цей режим працює також за замовчуванням, якщо взагалі не викликати метод).
* **`.values()`** — цикл перебирає лише **значення** словника, ігноруючи самі ключі.
* **`.items()`** — найпотужніший метод. Він повертає одночасно і **ключ**, і **значення** у вигляді пари. При цьому в циклі `for` використовують одразу дві змінні через кому.

**Приклад використання `.items()`:**

```python
# Словник із версіями технологій
tech_versions = {"Python": "3.11", "Django": "4.2"}

# Перебираємо ключі та значення одночасно
for technology, version in tech_versions.items():
    print(f"Технологія {technology} має версію {version}")

```

При кожній ітерації перша змінна (`technology`) автоматично отримує ключ, а друга змінна (`version`) — відповідне йобо значення.
