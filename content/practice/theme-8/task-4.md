# Задача 8.4: Творче завдання — комплексний аналіз та агрегація даних у словниках

### 🏆 Рівень складності: **Творчий** (Data Structures Integration)


## 📘 Короткі теоретичні відомості

У реальних інженерних проєктах та аналітиці структури даних майже завжди комбінуються. Найбільш поширений паттерн — це **список словників** (масив об'єктів), де кожен елемент списку є окремим словником із набором фіксованих характеристик.

При роботі з такими структурами алгоритм обробки складається з кількох кроків:

1. **Зовнішня ітерація:** цикл `for` проходить по всьому списку елемент за елементом.
2. **Внутрішній аналіз:** на кожному кроці змінна циклу стає окремим словником, і ми можемо звертатися до його конкретних ключів для перевірки умов (`if`).
3. **Агрегація результатів:** створення окремого словника-звіту для накопичення фінальних інженерних або бізнес-показників.

Такий підхід є базою для обробки даних, які повертають бази даних (наприклад, PostgreSQL чи MongoDB) або зовнішні API-сервіси.

## 🎯 Технічне завдання

Виявіть архітектурну креативність! Уявіть, що ви розробляєте аналітичний модуль для моніторингу репозиторіїв та оцінювання активності студентів на нашій навчальній платформі. Система має пройтися по базі даних виконаних практичних робіт (коммітів коду) та сформувати підсумковий словник-звіт: порахувати загальну кількість надісланих завдань та окремо виділити кількість робіт, які були зараховані (мають статус `"passed"`).

Напишіть скрипт для комплексного аналізу даних, який виконує такі кроки:

1. **Вхідні дані:**

Створіть список словників `submissions`, який імітує логи перевірки коду:
```python
submissions = [
    {"task": "4.4", "student": "Максим", "status": "passed"},
    {"task": "5.1", "student": "Анна", "status": "failed"},
    {"task": "5.2", "student": "Дмитро", "status": "passed"},
    {"task": "5.3", "student": "Анна", "status": "passed"},
    {"task": "5.4", "student": "Максим", "status": "failed"}
]

```

2. **Ініціалізація акумулятора:**

Створіть фінальний словник-звіт `report` із початковими нульовими показниками:
```python
report = {
    "total_submissions": 0,
    "passed_submissions": 0
}

```

3. **Алгоритм обробки:**

   * За допомогою циклу `for` переберіть список `submissions`. Назвіть змінну циклу `sub`.
   * На кожній ітерації циклу (для кожного знайденого комміту):
     1. Збільште значення за ключем `"total_submissions"` у словнику `report` на `1`.
     2. За допомогою оператора `if` перевірте умову: чи дорівнює значення за ключем `"status"` у поточному словнику `sub` рядку `"passed"`.
     3. Якщо умова виконується (`True`), збільште значення за ключем `"passed_submissions"` у словнику `report` на `1`.

4. **Виведення звіту:**

Після повного завершення роботи циклу виведіть у консоль фінальний словник-звіт точного формату:
`Аналітичний звіт платформи: [значення_словника_report]`
