# Задача 8.2: Модифікація словників та безпечне отримання даних за допомогою .get()

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Керування станом об'єктів)

## 📘 Короткі теоретичні відомості

Словники в Python є **змінними (mutable)**. Це означає, що ми можемо додавати нові пари `ключ: значення`, змінювати наявні або видаляти їх під час виконання програми.

### 1. Модифікація та додавання елементів

Щоб оновити значення для наявного ключа або створити новий елемент, використовують простий оператор присвоювання `=`:
`словник[ключ] = нове_значення`

```python
student = {"name": "Олег", "grade": 60}
student["grade"] = 85   # Оновлення наявного ключа
student["group"] = "IP"  # Створення нового ключа, якого не було

```

### 2. Безпечне зчитування за допомогою методу `.get()`

Якщо ми спробуємо звернутися до ключа, якого немає у словнику (наприклад, `student["age"]`), програма негайно зупиниться з помилкою `KeyError`.

Щоб уникнути аварійної зупинки коду, професійні розробники використовують вбудований метод **`.get(key, default)`**.

* Якщо ключ є у словнику, метод повертає його значення.
* Якщо ключа немає, метод повертає спеціальне значення `None` або ваш власний текстовий замінник (значення `default`), який ви вкажете другим аргументом.

```python
# Безпечний пошук ключа "age". Якщо його немає — поверне "Не вказано"
user_age = student.get("age", "Не вказано") 
print(user_age)  # Виведе: Не вказано (замість помилки KeyError!)

```
