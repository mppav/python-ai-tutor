# Задача 8.1: Створення базового словника та доступ за ключем

### 🏆 Рівень складності: **Репродуктивний** (Базові операції)

## 📘 Короткі теоретичні відомості

Досі ми вивчали списки, де кожен елемент мав свій порядковий номер (індекс). Проте в реальному житті ми часто шукаємо інформацію не за номерами, а за назвами: наприклад, слово у мовному словнику або номер телефону за іменем людини.

Для таких задач у Python існує тип даних **словник (`dict`)**. Словник — це неперелічена структура даних, яка зберігає інформацію у вигляді пар **`ключ: значення`**.

Основні правила роботи зі словниками:

* Словник створюється за допомогою фігурних дужок `{}`.
* Пари `ключ: значення` розділяються між собою комами, а сам ключ відокремлюється від значення двокрапкою.
* Щоб отримати значення, після назви словника вказують квадратні дужки з потрібним ключем: `словник[ключ]`.

**Приклад:**

```python
# Оголошення словника
user_profile = {
    "username": "cherednyk_dev",
    "role": "mentor",
    "level": "Middle"
}

# Доступ до даних за ключем
print(user_profile["username"])  # Виведе: cherednyk_dev
print(user_profile["level"])     # Виведе: Middle

```
