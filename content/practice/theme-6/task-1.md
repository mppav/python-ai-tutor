# Задача 6.1: Базовий цикл for та функція range()

### 🏆 Рівень складності: **Репродуктивний** (Базові операції)

## 📘 Короткі теоретичні відомості

Окрім циклу `while`, у мові Python існує інший, надзвичайно популярний тип циклу — **`for`**. Якщо цикл `while` працює, поки виконується умова, то цикл `for` використовується для перебору елементів певної послідовності (елементів списку, символів рядка або послідовності чисел).

Для автоматичної генерації послідовності чисел у циклі `for` використовують вбудовану функцію **`range()`**.

Вона може приймати від одного до трьох аргументів:

* **`range(stop)`** — генерує послідовність чисел від `0` до `stop` (**НЕ включаючи** саме число `stop`).
* **`range(start, stop)`** — генерує числа від `start` (включно) до `stop` (не включаючи).
* **`range(start, stop, step)`** — генерує числа від `start` до `stop` із кроком `step`.

**Приклад:**

```python
# Перебір чисел від 0 до 2
for i in range(3):
    print("Крок №", i)

```

*У цьому прикладі змінна `i` (її називають змінною циклу або ітератором) на кожному кроці автоматично набуває наступного значення з послідовності: спочатку `0`, потім `1`, і нарешті `2`.*
