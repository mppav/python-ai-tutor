# Задача 6.4: Творче завдання — побудова текстових графіків

### 🏆 Рівень складності: **Творчий** (Візуалізація даних)

## 📘 Короткі теоретичні відомості

У часи, коли комп'ютери ще не мали графічних інтерфейсів, інженери виводили графіки функцій, діаграми та малюнки безпосередньо у текстову консоль. Такий підхід називається **ASCII-графікою**.

Для автоматизації побудови таких графіків ідеально підходять цикли. Окрім математичних обчислень, у Python можна використовувати дуже зручну операцію — **дублювання рядків**. Якщо помножити текстовий рядок на ціле число за допомогою оператора `*`, Python повторить цей рядок відповідну кількість разів.

**Приклад:**

```python
print("*" * 5)  # Виведе: *****

```

Поєднуючи цикл `for`, функцію `range()` та множення рядків, можна динамічно змінювати довжину текстових ліній на кожному кроці й малювати графіки або геометричні фігури.

## 🎯 Технічне завдання

Виявіть інженерну креативність! Створіть консольний модуль для візуалізації навантаження серверної інфраструктури. Програма повинна за допомогою циклу `for` згенерувати текстову горизонтальну діаграму (гістограму), яка імітує плавне зростання графіка навантаження CPU.

Напишіть скрипт, який виконує такі кроки:

1. Напишіть цикл `for` зі змінною `step`, яка за допомогою функції `range()` послідовно набуває значень **від `1` до `10` включно** (це будуть кроки нашого моніторингу).
2. Усередині циклу створіть змінну `bar_length`, яка вираховує довжину графічного стовпчика для поточного кроку. Нехай довжина дорівнює значенню `step`, помноженому на `2` (тобто на першому кроці довжина буде 2, на другому — 4, на третьому — 6 і так далі).
3. Виведіть кожен рядок графіка в консоль чітко за таким шаблоном:
`Крок [значення_step]: [символи_зірочок_повторені_bar_length_разів]`

**Очікуваний вигляд графіка в консолі:**

```text
Крок 1: **
Крок 2: ****
Крок 3: ******
...
Крок 10: ********************

```
