# Задача 6.3: Вкладені цикли (Nested Loops) та генерація таблиць

### 🏆 Рівень складності: **Реконструктивний** (Вкладена логіка)

## 📘 Короткі теоретичні відомості

У програмуванні всередині тіла одного циклу можна викликати інший цикл. Таку конструкцію називають **вкладеними циклами (Nested Loops)**.

Логіка їхньої роботи підпорядкована простому правилу: на кожну **одну** ітерацію зовнішнього циклу внутрішній цикл виконується **повністю** (від початку до кінця).

Вкладені цикли ідеально підходять для обробки та генерації двовимірних структур даних: матриць, координатних сіток або таблиць.

**Приклад структури:**

```python
for x in range(1, 3):      # Зовнішній цикл (наприклад, рядки)
    for y in range(1, 4):  # Внутрішній цикл (наприклад, стовпчики)
        print(f"Координата: {x}, {y}")

```

## 🎯 Технічне завдання

Уявіть, що ви створюєте аналітичну панель (Dashboard) для відображення матриці завантаження серверних ядер або генеруєте математичний тренажер для студентів нашої платформи.

Напишіть програму, яка за допомогою вкладених циклів `for` автоматично генерує та виводить у консоль фрагмент **таблиці множення** для чисел від 1 до 3:

1. Напишіть зовнішній цикл `for` зі змінною `i`, яка через функцію `range()` послідовно набуває значень **від `1` до `3` включно**. Ця змінна відповідатиме за перший множник (рядок таблиці).
2. Усередині нього напишіть внутрішній цикл `for` зі змінною `j`, яка через функцію `range()` так само набуває значень **від `1` до `3` включно**. Ця змінна відповідатиме за другий множник (стовпчик таблиці).
3. У самому центрі (в тілі внутрішнього циклу) створіть змінну `result`, яка обчислює добуток `i * j`.
4. Виведіть кожен крок обчислення в консоль точного формату:
`[значення_i] x [значення_j] = [значення_result]`
