# Задача 9.2: Функції з параметрами та аргументами

### 🏆 Рівень складності: **Репродуктивно-конструктивний** (Вхідні параметри)


## 📘 Короткі теоретичні відомості

Функції стають набагато потужнішими, коли вони можуть приймати та обробляти зовнішні дані. Для цього під час оголошення функції всередині круглих дужк вказують **параметри** — спеціальні змінні-замінники.

* **Параметри** — це змінні, які ми прописуємо в описі функції (шаблоні). Вони існують лише всередині цієї функції.
* **Аргументи** — це реальні значення, які ми передаємо у функцію в момент її виклику.

**Приклад:**

```python
# Оголошення функції з двома параметрами: name та version
def print_software_info(name, version):
    print(f"Програма: {name}, Версія: {version}")

# Виклик функції з реальними аргументами
print_software_info("Docker", "24.0") # Виведе: Програма: Docker, Версія: 24.0
print_software_info("PostgreSQL", "15") # Виведе: Програма: PostgreSQL, Версія: 15

```

Коли функція викликається, Python автоматично присвоює значення аргументів відповідним параметрам за їхнім порядком.


## 🎯 Технічне завдання

Уявіть, що ви розробляєте автоматизовану систему логування для CI/CD конвеєра (конвеєра розгортання коду) нашої освітньої платформи. Вам потрібно створити універсальну функцію, яка форматує та виводить у консоль повідомлення про стан виконання різних системних завдань.

Напишіть інженерний скрипт, який реалізує цю логіку:

1. Оголосіть функцію з назвою `log_service_status`, яка приймає два параметри: `service_name` (назва сервісу або завдання) та `status_code` (поточний статус).
2. Усередині тіла функції за допомогою **однієї** команди `print()` виведіть повідомлення чітко за таким шаблоном:
`[СИСТЕМА] Сервіс: [значення_service_name] перейшов у стан: [значення_status_code]`
3. Нижче, поза межами функції, виконайте два окремі виклики вашої функції з такими аргументами:
   
* Перший виклик: передайте назву сервісу `"Celery"` та статус `"RUNNING"`.
