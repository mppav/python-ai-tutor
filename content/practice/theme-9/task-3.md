# Задача 9.3: Повернення значень за допомогою оператора return

### 🏆 Рівень складності: **Реконструктивний** (Обробка та повернення даних)


## 📘 Короткі теоретичні відомості

У попередніх задачах наші функції просто виводили текст у консоль за допомогою `print()`. Проте в реальному програмуванні головне завдання більшості функцій — обчислити певний результат і **повернути** його назад у головну програму, щоб цей результат можна було зберегти у змінну, передати в іншу функцію або використати в математичних розрахунках.

Для повернення результату з функції використовують ключове слово **`return`**.

> ⚠️ **Критично важливе правило:** Як тільки інтерпретатор Python натрапляє на оператор `return`, функція **миттєво завершує свою роботу**. Будь-який код, написаний у тілі функції *нижче* оператора `return`, виконаний не буде.

**Приклад:**

```python
def multiply(a, b):
    product = a * b
    return product  # Повертаємо результат обчислення

# Виклик функції та збереження результату в змінну
result_data = multiply(5, 4)
print("Результат обчислення:", result_data)  # Виведе: 20

```

Уявіть, що ви розробляєте архітектуру білінг-модуля (модуля оплати) для нашої освітньої платформи. Вам потрібно створити функцію, яка вираховує фінальну вартість курсу для студента з урахуванням його персональної знижки у відсотках.

Напишіть інженерний скрипт, який реалізує цю математичну логіку:

1. Оголосіть функцію з назвою `calculate_discount_price`, яка приймає два параметри: `base_price` (початкова ціна курсу) та `discount_percent` (відсоток знижки).
2. Усередині функції обчисліть фінальну вартість за математичною формулою:
`final_price = base_price - (base_price * discount_percent / 100)`
3. За допомогою оператора **`return`** поверніть отримане значення `final_price` з функції.
4. Поза межами функції виконайте її виклик, передавши початкову ціну `1000` (грн) та знижку `15` (%). Збережіть повернутий результат у змінну `course_cost`.
5. Виведіть у консоль повідомлення точного формату:
`Вартість навчання з урахуванням знижки: [значення_змінної_course_cost] грн.`
